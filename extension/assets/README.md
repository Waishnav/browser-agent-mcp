# Extension Icons

This directory should contain the following icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)  
- icon128.png (128x128 pixels)

For now, you can use any square images or generate simple icons.
The icons represent the Browser Agent MCP extension in the browser toolbar and extensions page.

## Quick Icon Generation

You can create simple placeholder icons using online tools like:
- https://favicon.io/
- https://www.favicon-generator.org/

Or use the emoji 🤖 as the icon design theme.
