# Browser Agent MCP - Chrome Extension Icons

This directory should contain the extension icons:
- icon-16.png (16x16 pixels)
- icon-48.png (48x48 pixels)
- icon-128.png (128x128 pixels)

These icons represent the Browser Agent MCP extension in the Chrome toolbar and extension management page.

To generate icons, you can use any image editing tool or SVG to PNG converter with the appropriate sizes.
