4. Complete Visual Flow

Here's what the agent sees and does during a typical interaction:

→ Agent receives command: "Click the Submit button"
→ Agent cursor (🎯) moves to Submit button
→ Action display shows: "Clicking: Submit button"
→ Click event is triggered
→ Cursor pulses briefly
→ Page snapshot is returned to MCP server
✓ Action complete

Commands:
• browser_create_tab - Create new tab
• browser_switch_tab - Switch to tab
• browser_close_tab - Close tab
• browser_list_tabs - List all tabs

6. Installation & Usage

Get started in 3 simple steps:

Step 1: Build the project
$ npm install
$ npm run build

Step 2: Load Chrome extension
1. Open chrome://extensions/
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the 'extension' folder

Step 3: Connect and use
1. Click extension icon
2. Click "Connect This Tab"
3. Start automating with your AI assistant!
